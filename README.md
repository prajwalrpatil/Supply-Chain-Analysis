# Supply Chain Analysis Dashboard

## Project Overview
This project analyzes supply chain data to understand business performance, supplier efficiency, inventory management, logistics, and product quality.

## Objectives
- Analyze supply chain performance.
- Evaluate supplier and manufacturing performance.
- Understand inventory and demand patterns.
- Analyze logistics and transportation.
- Compare product quality and performance.

## Tools Used
- Power BI
- Microsoft Excel (if used)

## Project Structure
- Dashboard_Screenshots: Dashboard visualizations.
- Project_Presentation: Project presentation.
- Project_Report: Detailed project report.

## Key Insights
Key findings are documented in the project report.

## Conclusion
This project demonstrates how data analysis and visualization can help businesses monitor supply chain operations and make informed decisions.
